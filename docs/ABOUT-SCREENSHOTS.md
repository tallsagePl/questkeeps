# Скриншоты страницы «О проекте»

Сняты с реального интерфейса QuestKeeps скриптом scripts/capture-about.mjs. Все запросы /api/* перехватываются локальными демонстрационными данными; браузер создаётся без пользовательского профиля и cookie. В кадрах нет реальных пользователей, email, OAuth-токенов и личных фотографий. Карта показывает публичные ориентиры Стамбула; атрибуция Esri / OpenStreetMap остаётся в кадре.

Скрипт сохраняет три экрана для каждого сочетания ru/en и light/dark в public/about/screenshots. Запуск: node scripts/capture-about.mjs при работающем локальном сайте. Допускается только loopback-адрес. Результаты — WebP с заданными размерами, около 1 МБ на все 12 файлов; на странице загружаются три изображения текущей темы и языка.

В широкой версии карточки выпрямляются при наведении и клавиатурном фокусе; каждая ссылка открывает полный скриншот. На узком экране — горизонтальная лента. prefers-reduced-motion отключает преобразования и переходы. Личные данные для повторной съёмки добавлять не нужно.
