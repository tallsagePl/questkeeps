# Публикации из поездок

В шапке поездки есть кнопка «Поделиться поездкой». Можно выбрать пост (1080 × 1350, до пяти фото в коллаже) или 1–5 историй (1080 × 1920, по кадру на историю). Заголовок, выбор фотографий и способ размещения редактируются перед созданием. PNG формируются в браузере; оригиналы и EXIF не прикрепляются к файлам.

Конструктор исключает скрытые, скрытые от гостей, пропавшие кадры и видео. Ссылка по умолчанию ведёт на QuestKeeps. Владелец может явно включить ссылку на поездку; если гостевой просмотр ещё закрыт, форма объясняет его включение. Гость использует уже выданную ему ссылку. Участник не получает право включать или менять гостевой доступ.

Файлы передаются через стандартное меню устройства только после проверки поддержки файлов через Web Share. На остальных устройствах каждый PNG можно скачать отдельно. Публикацию подтверждает сам пользователь в выбранном приложении. В Instagram Stories ссылку нужно добавить стикером; в Telegram можно прикрепить файлы и подпись. Кнопка Telegram для ссылки передаёт только текст и адрес, не изображения.

- [Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API)
- [Telegram Sharing Button](https://core.telegram.org/widgets/share)
- [Instagram link stickers — Meta](https://about.fb.com/ja/news/2021/10/linkaccessstickers/)

Оформление находится в lib/share-cards.ts; редактор — в components/archive/publish-dialog.tsx. При изменении бренда нужно обновить и эти шаблоны, сверившись с DESIGN.md. Проверки: фильтрация приватных кадров, реальные размеры PNG, пять файлов для историй, явное включение гостевого доступа и вёрстка на телефоне.
