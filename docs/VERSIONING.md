# Версии QuestKeeps

Используем формат MAJOR.MINOR.PATCH.

- MAJOR — глобальное изменение приложения или несовместимые изменения.
- MINOR — новые возможности; PATCH при этом сбрасывается в 0.
- PATCH — исправления ошибок без новых возможностей.

Версию одновременно обновляем в package.json и package-lock.json. Например: 1.1.0 — выпуск с новыми функциями; 1.1.1 — исправление этого выпуска.

Git-репозиторий хранится локально. Отправка во внешние репозитории выполняется только по отдельному запросу. Данные пользователей, фотографии, секреты и локальные настройки окружения в историю исходного кода не включаются.
