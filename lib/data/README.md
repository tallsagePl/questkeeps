# Localized place names

place-names.json is generated by scripts/build-place-names.py from GeoNames cities1000.zip and alternateNamesV2.zip, downloaded on 2026-10-20:

- https://download.geonames.org/export/dump/cities1000.zip
- https://download.geonames.org/export/dump/alternateNamesV2.zip
- Format: https://download.geonames.org/export/dump/readme.txt
- Data license: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/
- Attribution: GeoNames, https://www.geonames.org/ ; original city positions/names from cities.json (same GeoNames source/license).

The join requires the same country, original name and coordinates rounded to five decimal places. Current non-colloquial, non-historic labels are preferred. English uses the English alternate label, then GeoNames ASCII name; Russian uses the Russian alternate label, then the recorded Cyrillic native name. Missing labels preserve the existing original name at runtime; no algorithmic transliteration is used. Entries identical to the original English name are omitted to reduce size.

The generated snapshot matches 171,054 cities with 70,370 Russian names, compacted into 96,125 override entries. The dataset stays on the server. Only labels of the detected route are returned to the browser. End users do not need a GeoNames account or a network call for names.

place-name-overrides.json supplies reviewed exceptions by exact place identity:

- Коньяалты: https://antalya.tc/goroda/konyaalty
- Анталья: the municipality's Russian page, https://www.antalya.bel.tr/ru/iletisim

To rebuild, run Python 3 on scripts/build-place-names.py. Source archives are cached in the ignored data/geonames-downloads directory; only the compact JSON snapshot belongs with the source. Reviewed overrides are separate and survive regeneration.
